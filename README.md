# SWYNEX – Exploratory Data Analysis (Retail Sales)

An exploratory data analysis (EDA) of retail sales data: cleaning the raw data, summarising it, and visualising the main patterns.

## Project Overview

- **Goal:** Understand sales performance and spot trends, outliers and data quality issues.
- **Dataset:** Retail sales data (cleaned version included as `retail_sales_clean.csv`).
- **Tools:** Python, pandas, matplotlib / seaborn.

## Repository Contents

| File / Folder | Description |
|---|---|
| `README.md` | Project description (this file) |
| `eda_analysis.py` | Python script that cleans the data and runs the analysis |
| `eda_output.txt` | Text output of the analysis (summary statistics, checks) |
| `retail_sales_clean.csv` | Cleaned dataset used for the analysis |
| `eda_dashboard.html` | Interactive dashboard – download and open in a browser |
| `charts/` | Chart images generated by the analysis |

## Methodology

1. **Load data** – read the raw retail sales file.
2. **Clean data** – handle missing values, duplicates and incorrect data types.
3. **Summarise** – descriptive statistics for key columns.
4. **Visualise** – charts for sales trends, categories and distributions.
